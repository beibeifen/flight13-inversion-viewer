# 方法与可辨识性

## 信息层级

方法把数据严格分成四层；公开演示包只用结构相同的合成量展示界面和公式：

1. 视频直接观测：时间、屏显速度/高度、发动机图标、HUD 模式、圆弧像素、可见姿态与画面事件。
2. 第三方公开遥测回放：StarDash 从 SpaceX 公共直播上游生成的位置点。它不是本项目独立测得的真值，也可能与 HUD 共享上游。
3. 无尺度派生：模式门控、质量控制后，把一级和二级圆弧分别映射为 `q_B,q_S∈[0,1]`。两级指标没有共同的物理尺度，不能直接相加。
4. 外部情景：用总质量、级间占比和两个保留质量，把 `q_B,q_S` 映射为吨位。

## 轨迹点

私有研究查看器中的稀疏原始点来自第三方 StarDash public-feed 回放。数据间隔并非固定十秒；原始候选点约为十秒量级，页面的密集轨迹是对这些点做时间插值后的显示几何，不是新增观测。公开仓库不分发这些原始点，其内置轨迹是明确标注的合成演示曲线。

速度、区间路径和其他运动学量只在被允许的相邻原始点区间内计算。跨越硬缺口时不插值。地球显示采用球面近似，数值重建使用 WGS84 ECEF/局部 ENU；屏幕坐标不能当作 ECEF。

## 发动机与推进剂圆弧

只有 HUD 中心确认为发动机阵列模式时，外圆弧才可作为推进剂图形候选。在 SPEED、ALTITUDE、姿态球或转场模式下，同一槽位具有别的语义，必须剔除。

推荐处理顺序：30 Hz 提取 → 每秒中位数 → 多阈值包络 → 切镜/强光/淡入淡出筛选 → 确认燃烧窗内的带权单调非增拟合。滑行或未显示区间只保持上一估计，并以非观测样式标记。不能用逐帧累计最小值，因为一次暗帧会永久把序列锁低。

一级和二级分别定义：

```text
q_B(t) = I_B(t)/100
q_S(t) = I_S(t)/100
0 ≤ q_B(t), q_S(t) ≤ 1
```

其中 `I_B`、`I_S` 是各自的 100→0 指数。它们各自在本级观察范围内归一化；`q_B+q_S` 没有总推进剂或总质量含义。

## 绝对质量情景

页面使用四个外部输入：

```text
M0 > 0
0 < w_B < 1
0 ≤ D_B ≤ w_B M0
0 ≤ D_S ≤ (1-w_B) M0
```

定义：

```text
M_B,0 = w_B M0
M_S,0 = (1-w_B) M0
P_B,0 = M_B,0 - D_B
P_S,0 = M_S,0 - D_S
M_B(t) = D_B + P_B,0 q_B(t)
M_S(t) = D_S + P_S,0 q_S(t)
M_stack(t) = M_B(t)+M_S(t),  t ≤ t_sep
```

分离后不再定义组合体总质量曲线。`D_B,D_S` 在界面上称“图形归零保留质量”：论文默认可解释为干质量假设，但视频本身不能证明圆弧的零点等于空箱，也不能识别残余推进剂。

默认情景：

```text
M0 = 4929 t
w_B = 3611/4929
D_B = 311 t
D_S = 118 t
P_B,0 = 3300 t
P_S,0 = 1200 t
```

若不引入 `M0,w_B,D_B,D_S`，视频只给出两个独立的无尺度指标。对任意 `λ>0`，把所有质量同时乘以 `λ` 都产生相同的 `q_B,q_S`，所以绝对吨位不可辨识。推力、Isp、气动、风场、总质量或其他外部约束缺失时，速度/高度/轨迹不能单独解除这个尺度退化。
